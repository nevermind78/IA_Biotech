Google Colab en bref

Google Colaboratory est un service gratuit de Google qui exécute des notebooks Jupyter dans le cloud : pas d’installation, des bibliothèques scientifiques déjà présentes, et un accès à des GPU (cartes graphiques) indispensables au deep learning.

Les gestes essentiels dans Colab
Action Comment
Exécuter une cellule Maj + Entrée (ou bouton ▶)
Tout exécuter Exécution → Tout exécuter (Ctrl + F9)
Repartir de zéro Exécution → Redémarrer la session
Activer le GPU Exécution → Modifier le type d'exécution → GPU T4
Sauvegarder son travail Fichier → Enregistrer une copie dans Drive
Ajouter une cellule boutons + Code / + Texte
Afficher une solution masquée double-clic sur la cellule « 💡 Solution »
AttentionColab est temporaire
  • Une session inactive est coupée au bout d’un certain temps ; une session dure au maximum quelques heures.
  • À la coupure, les variables et les fichiers créés sont perdus (pas le notebook enregistré dans Drive).
  • L’accès gratuit au GPU est limité : désactivez-le (Modifier le type d'exécution → CPU) quand vous n’en avez pas besoin.

Comment se lit un notebook de l’atelier

Les formulaires Colab permettent de modifier un paramètre sans toucher au code :

N_ARBRES = 200   #@param {type:"slider", min:10, max:500, step:10}
CIBLE = "NR-AhR" #@param ["NR-AhR", "SR-MMP", "SR-p53"]

Dans Colab, ces lignes s’affichent comme un curseur et un menu déroulant à droite de la cellule. Changez la valeur, puis ré-exécutez la cellule (et les suivantes qui en dépendent).

Les messages d’erreur les plus fréquents

Lire une erreur : regardez toujours la dernière ligne du message
Erreur Cause probable Solution
NameError: name 'x' is not defined cellule qui définit x non exécutée, ou faute de frappe exécuter les cellules précédentes dans l’ordre
ModuleNotFoundError: No module named ... bibliothèque non installée exécuter la cellule %pip install en début de notebook
KeyError: 'colonne' nom de colonne ou de clé inexistant vérifier l’orthographe avec df.columns
IndentationError décalage (espaces) incorrect aligner le code avec 4 espaces
CUDA out of memory mémoire du GPU saturée réduire la taille des lots, redémarrer la session

## Google Colab en bref

**Google Colaboratory** est un service gratuit de Google qui exécute des notebooks Jupyter **dans le
cloud** : pas d'installation, des bibliothèques scientifiques déjà présentes, et un accès à des **GPU**
(cartes graphiques) indispensables au deep learning.

| Action | Comment |
|---|---|
| Exécuter une cellule | `Maj + Entrée` (ou bouton ▶) |
| Tout exécuter | `Exécution → Tout exécuter` (`Ctrl + F9`) |
| Repartir de zéro | `Exécution → Redémarrer la session` |
| Activer le GPU | `Exécution → Modifier le type d'exécution → GPU T4` |
| Sauvegarder son travail | `Fichier → Enregistrer une copie dans Drive` |
| Ajouter une cellule | boutons `+ Code` / `+ Texte` |
| Afficher une solution masquée | double-clic sur la cellule « 💡 Solution » |

: Les gestes essentiels dans Colab {.striped}

::: {.callout-warning}
## Colab est temporaire
- Une session inactive est **coupée** au bout d'un certain temps ; une session dure au maximum quelques heures.
- À la coupure, **les variables et les fichiers créés sont perdus** (pas le notebook enregistré dans Drive).
- L'accès gratuit au GPU est **limité** : désactivez-le (`Modifier le type d'exécution → CPU`) quand vous n'en avez pas besoin.
:::

## Les messages d'erreur les plus fréquents

| Erreur | Cause probable | Solution |
|---|---|---|
| `NameError: name 'x' is not defined` | cellule qui définit `x` non exécutée, ou faute de frappe | exécuter les cellules précédentes dans l'ordre |
| `ModuleNotFoundError: No module named ...` | bibliothèque non installée | exécuter la cellule `%pip install` en début de notebook |
| `KeyError: 'colonne'` | nom de colonne ou de clé inexistant | vérifier l'orthographe avec `df.columns` |
| `IndentationError` | décalage (espaces) incorrect | aligner le code avec 4 espaces |
| `CUDA out of memory` | mémoire du GPU saturée | réduire la taille des lots, redémarrer la session |
